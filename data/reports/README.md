# Daily reports

One report per trading evening, written by the system after the market closes:

```
data/reports/2026-10/2026-10-12.md    (a folder per month, a file per day)
```

The first report appears when paper trading goes live (M6). Until then:

- [A sample report](../../docs/reports/m4-sample-daily-report.md), built from a real day (9 September 2026)
- [How to read the daily report](../../docs/how-to-read-the-daily-report.md)

Nothing in the system reads these files; they are written for you.
