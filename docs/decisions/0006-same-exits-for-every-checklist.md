# 0006 — The same exits for every checklist

**Decided.** Stop at one typical daily move below the close; target at 1.5 typical daily moves above; sell after 3 trading days.

**Considered.** Each checklist with its own exits (e.g. a breakout's stop below its range).

**Why.** With the same exits, differences in results come down to the entry conditions, which is what Learn is trying to measure. Fewer moving parts. A checklist can get its own exits later as a new version.
